# TMAG Specimen Metadata Request Draft

Subject: Request for collection metadata for `Galaxias pedderensis` lots from the TMAG ichthyology collection

Hello,

I’m working with collaborators on a historical reconstruction and conservation-analysis project for the Pedder galaxias, *Galaxias pedderensis*, associated with the Lake Pedder system in southwest Tasmania.

We have already compiled the publicly available ALA / OZCAM records for TMAG ichthyology material, but many of the core `G. pedderensis` lots that are directly relevant to the Pedder chronology appear online without collection dates, and a small number also lack usable locality detail in the public feed.

Would it be possible to provide either:

1. a CSV export for the attached TMAG Pedder galaxias lot list, or
2. scans / photos of the corresponding specimen labels and register entries

for the lots listed in `data/ala/tmag_pedderensis_request_list.csv`?

The fields that would be most valuable are:

- collection date
- collector / recorded by
- locality / waterbody / any finer site description
- event remarks or collection notes
- individual count where available
- identification history or later redeterminations
- any linked label or register scans

This would let us complete a specimen-level chronology for the original Pedder system and better reconcile museum evidence with the published survey and translocation history.

At this stage the highest priority is the `30` TMAG `G. pedderensis` lots in the attached list. If useful, we can follow up later with a second, lower-priority request for selected `G. brevipinnis` and `G. parvus` Pedder-linked lots.

I’m very happy to work with whatever export format is easiest from your side. If helpful, I can also send the list back as plain text in the body of the email rather than as an attachment.

Many thanks for considering this request.

Best wishes,

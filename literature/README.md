# Literature Staging

This folder is the best place to drop source material that is not itself part of the project narrative or data products.

Suggested structure:

- `literature/pedder/`: Pedder-specific papers, reports, genetics papers, and recovery documents.
- `literature/comparative/`: comparator systems such as `Galaxias johnstoni`, Clarence Lagoon, trout-vs-galaxiid papers, and New Zealand proxy studies.
- `literature/grey/`: agency reports, scans, unpublished reports, and difficult-to-source grey literature.

Conventions:

- Preserve original filenames where possible.
- If you create a markdown or OCR text version of a PDF, keep the same basename beside it when practical.
- Keep source documents untouched; put your own notes in separate `*_notes.md` files if needed.
- Once new material lands here, the next step will be to register it in `data/source_register.csv` and pull relevant observations into `data/evidence_ledger.csv`.
